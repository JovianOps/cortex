Architecture

            
Built for verifiable results, not vague prompts

          

        


        

          

            

              
            

            
Deterministic Stop Gates

            
Every v0.2.0 playbook requires inspecting source inputs, running real linters, Decimal scripts, or EXPLAIN plans, and tagging unverified claims explicitly.

          


          

            

              
            

            
20-Task A/B Eval Suite

            
Includes evals/skill_evals.json and scripts/eval_skills.py with 100-point rubrics to measure Without-Skill vs. With-Skill score lift.

          


          

            

              
            

            
Native Shell, Zero Extra Tools

            
Every skill ships as a CI-verified ZIP and installs cleanly with native Bash or PowerShell loops — no jq, xargs, or custom package manager needed.
